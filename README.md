# smart-city-parking-tracker
A Smart City Parking Tracker that helps users find available parking spaces, analyze parking occupancy, and explore traffic and route information.

Features
🅿️ Total parking spaces
🟢 Available parking spaces
🔴 Occupied parking spaces
📊 Parking occupancy analysis
🔎 Search and filter parking locations
🚦 Traffic information
🗺️ Map/direction support
📈 Interactive charts
📍 Parking location analysis

🛠️ Technologies
Python
Streamlit
Pandas
Plotly
SQLite
